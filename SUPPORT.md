# Support

AWS Tunnel Desk is maintained by an open source community and is provided without a service-level agreement.

## Getting help

1. Read [README.md](README.md), especially Runtime requirements and Security model.
2. Run the application's environment pre-flight check.
3. Search existing issues.
4. Open a bug report with sanitized diagnostics if the problem remains.

Never post credentials, SSO tokens, account IDs, private endpoints, database names, customer data, or unredacted logs.

Questions about AWS account policy, network architecture, database permissions, or production incident response may require support from your AWS administrator or a qualified cloud professional.
